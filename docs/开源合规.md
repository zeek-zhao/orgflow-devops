> 这份文档回答一件事：**我们已经在对公众分发，那么欠了谁什么、欠的东西放在哪、怎么证明它还在。**
> 2026-11-11 的评估判定为「不可发布（D 级）」，三项 P0 已在本批修复；本文记录修复后的口径与后续维护规则。

## 1. 分发事实（义务的触发点）

合规义务只在「分发」发生时触发，所以先确认事实，而不是假设。

本项目把 13 个容器镜像推送到 GHCR（`ghcr.io/zeek-zhao/orgflow-devops/*`），
且这些包**匿名可拉取**（不带任何凭据即可换到 pull token）：

```bash
curl -s -o /dev/null -w '%{http_code}\n' \
  "https://ghcr.io/token?scope=repository:zeek-zhao/orgflow-devops/mirror-homepage:pull&service=ghcr.io"
# → 200
```

**结论：对公众的分发已经发生**，GPL-2.0 / GPL-3.0 / EPL-1.0 的义务此刻即生效，
不因为「仓库还是 private」而豁免。仓库可见性与镜像可见性是两件事——这一点最容易误判。

## 2. 义务矩阵（谁要什么，我们放在哪）

| 组件 | 许可证 | 条款要求 | 我们的落地位置 |
|---|---|---|---|
| Homepage | GPL-3.0 | §4/§6：随附许可证 + Corresponding Source 指引 | `public/licenses/GPL-3.0.txt` + NOTICES §4.1 |
| phpLDAPadmin | GPL-2.0 | §1：随附许可证副本 | `public/licenses/GPL-2.0.txt` + NOTICES §4.1 |
| dnsmasq | GPL-2.0 | 同上 | 同上（镜像 label 指向 licenses/） |
| Nexus Repository | EPL-1.0 | §3：源码可得性声明 | `public/licenses/EPL-1.0.txt` + NOTICES §4.3 |
| OpenLDAP | OpenLDAP PL 2.8 | 保留版权声明 + 随附副本 | `public/licenses/OpenLDAP-2.8.txt` |
| Caddy / Dex | Apache-2.0 | §4：保留版权与 NOTICE | `public/licenses/Apache-2.0.txt` |
| OAuth2 Proxy | MIT | 保留版权与许可声明 | `public/licenses/MIT.txt` |
| Ubuntu 基础镜像 | 多许可证 | 随镜像保留 `/usr/share/doc/*/copyright` | 镜像内原样，不额外处理 |

自建镜像（jenkins / jenkins-agent / router / jjb / dnsmasq / m0-test）的 `Dockerfile`
都带 `org.opencontainers.image.licenses` 标签，机器可读、可被扫描工具识别。

## 3. 维护规则（不遵守就会退回 D 级）

**新增或升级任何组件时，必须同步三处，缺一即视为声明不可信：**

1. `public/licenses/` —— 新增 copyleft 组件的许可证全文
2. `public/THIRD_PARTY_NOTICES.md` —— 组件、版本、上游地址、义务
3. `scripts/gen-sbom.py` 的 `DECLARED` 表 —— 机器可读的许可证声明

升级镜像时另有第四处：`tests/images.lock`（digest）与 `docker-compose.ghcr.yml`。

判定「新组件是不是 copyleft」不要看镜像 label：**实测 `sonatype/nexus3` 的 label 写
`Apache-2.0`，上游 `LICENSE.txt` 是 EPL-1.0**。要看上游仓库的 LICENSE 原文。

## 4. 验证命令（发布前四条，缺一不可）

```bash
make mirror                      # 导出 + 链接自洽 + 必需文件冒烟
bash scripts/check-public-redaction.sh .mirror-export   # 敏感字段门禁
make sbom                        # 声明式 SBOM（12 个镜像）
make cve                         # CVE 扫描（需 trivy；未装会明确失败，不假装干净）
```

`make mirror` 内部已含两条硬断言，且有反证记录（2026-11-11）：

- 缺 `docker-compose.yml` / `.env.example` / `THIRD_PARTY_NOTICES.md` → 直接拒绝发布
- 导出物里的悬空链接 → 自动降级为纯文本，再校验必须为 0

## 5. 已知不一致（照实写，不掩盖）

1. `sonatype/nexus3` 镜像 label 标 `Apache-2.0`，实际 EPL-1.0；已在 NOTICES §5 记录。
2. `osixia/phpldapadmin:0.9.0` 镜像内没有 GPL-2.0 全文；由 `licenses/GPL-2.0.txt` 补齐义务。
3. `gethomepage/homepage` 镜像内 `/usr/local/LICENSE` 是 Node.js 的许可，不是 GPL-3.0。
4. `oauth2-proxy` 的 LICENSE 只有 MIT 正文、无版权行（上游写法）。
