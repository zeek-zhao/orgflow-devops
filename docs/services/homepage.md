# homepage 服务手册

> 状态：适用 | 最后核对：2026-11-24 | 对应分支：feat/m0-v2

## 1. 职责
统一面板：HomePage（官方 gethomepage v2.7.0），占公网根路径 `/` 与内网 `home.<DOMAIN>`。渲染两组卡片，**域名一律用占位符**，改配置免重建容器。

## 2. 双分组与卡片（M0-v2 R1）
两组各 6 卡，`certs-init`（一次性任务）两组都不出现：

| 分组 | 回答的问题 | 卡的探测/入口 | description 前缀 |
|---|---|---|---|
| 局域网服务状态 | 服务在不在 | siteMonitor（HTTP 内网直连）/ ping（ICMP 或 localhost） | `[LAN]` |
| 域名入口 | 怎么进去 | href = `https://{{HOMEPAGE_VAR_PUBLIC_HOST}}<public_path>` | `[DOMAIN]` |

- **为什么用 description 前缀而不是 tags/weight**：官方 v2.7.0 的 service 字段无 `tags`/`weight`（已查证 https://gethomepage.dev/configs/services/），用「分组名 + 前缀」达成标签语义，顺序由 manifest 的 `order` 决定。
- **为什么 LDAP 目录不做 HTTP 探测**：LDAP 是 389 目录协议无 HTTP 端点，UI 侧经 ldapadmin 代理探测（description 已注明）；**真实 LDAP 校验在 `verify.sh` 的 `ldapsearch`**。
- **为什么 DNS 不做 HTTP 探测**：dnsmasq 是 53/udp，HTTP 探测恒红；卡片只用 `ping: dnsmasq`，真实 DNS 校验用 `dig @dnsmasq`。
- **自身卡探测用 localhost**：homepage 卡用 `http://localhost:3000/`，写域名会撞 `HOMEPAGE_ALLOWED_HOSTS`。

## 3. 动态注册（manifest 驱动，R2）
唯一真源 `services/manifest.tsv`（列：order/service/depends_on/health_url/monitor_url/ping_url/public_path/tags/ui_kind）。新增服务 = manifest 加一行 + 建 `services/<svc>/compose.yml`：
```
python3 scripts/render-homepage.py          # 渲染 config/homepage/services.yaml
python3 scripts/render-homepage.py --check  # 门禁：与 manifest 不一致返回非 0
```
生成物首行写死 `# GENERATED BY ... 禁止手改`；`up.sh` 启动 homepage 前自动渲染。未采用 Docker socket 方案（避免把宿主 Docker 控制权交给公网可达容器）。

## 4. 配置与外观
- `config/homepage/settings.yaml`：`startUrl: /`（不写 home，免 308）、`favicon: /favicon.ico`（真实文件，Dockerfile COPY，根治 404）、布局键 `局域网服务状态`/`域名入口`、无天气 widget（断网零裂图）。
- `HOMEPAGE_ALLOWED_HOSTS = ${PUBLIC_HOST},localhost,127.0.0.1`，无 `home.<domain>` 子域写法。
- `HOMEPAGE_VAR_PUBLIC_HOST` 由 compose 注入，取值 `${PUBLIC_HOST}`（遵循用户拍板：Funnel/ts.net 为默认）。

## 5. 启动 / 健康检查 / 用例 / 排障
- 启动：`up.sh --only homepage`（独立命名空间），隔离端口 8082，固定 IP .11。
- 健康：`curl -H 'Host: localhost' http://127.0.0.1:3000/` → 200；`/favicon.ico` 200。
- 用例：`tests/bats/S_homepage.bats` + `tests/bats/15_homepage.bats`（全栈）；断言 12 卡、href 全 https 无 `.local`、两分组名。
- 排障：卡片不显示 → 跑 `render-homepage.py --check` 看是否手改了生成物；裂图 → 确认无外链 CDN 图标；404 favicon → 确认镜像含 `/app/public/favicon.ico`。
