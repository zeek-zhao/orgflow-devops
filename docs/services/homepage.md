# homepage 服务手册

> 状态：适用 | 最后核对：2026-11-24 | 对应分支：feat/m0-release（R6 展示层重构后）

## 1. 职责
统一面板：HomePage（官方 gethomepage v2.7.0），占公网根路径 `/`（单域名路径型，T6 已删 `home.<DOMAIN>` 子域 vhost）。渲染两组卡片，**域名一律用占位符**，改配置免重建容器。

## 2. 双分组与卡片（R6 展示层重构后）
`certs-init`（一次性任务）两组都不出现。R6 起：**服务状态组 6 张、公网入口组 4 张**，不再有方括号前缀，description 统一为「一句中文用途 · 协议/端口」。

| 分组 | 回答的问题 | 卡片 | 探测/入口 |
|---|---|---|---|
| 服务状态 | 服务在不在 | DNS 解析、LDAP 目录、Caddy 网关、统一入口、LDAP 管理、路由服务（6 张） | siteMonitor（HTTP 内网直连）/ ping（ICMP 或 localhost）；href 指向各自 `public_path` |
| 公网入口 | 怎么进去 | 统一入口 `/`、LDAP 管理 `/ldapadmin/`、路由服务 `/router/healthz`、状态总览 `/status`（4 张） | href = `https://{{HOMEPAGE_VAR_PUBLIC_HOST}}<public_path>` |

- **公网入口筛选规则（写进 `scripts/render-homepage.py`，不写死服务名）**：服务进入「公网入口」组 = `manifest.public_path` 既不是 `/status` 也不是 `/none`；再固定追加一张「状态总览 → `/status`」卡（它是状态页入口本身，不是假入口）。因此 DNS/LDAP/Caddy 三张「点进去还是 `/status`」的重复卡不再进入该组。以后新增服务只要 `public_path` 是真实路径即自动进组，无需手改脚本。
- **为什么不用 tags/weight/方括号前缀**：官方 v2.7.0 的 service 字段无 `tags`/`weight`（已查证 https://gethomepage.dev/configs/services/）；R6 移除 `[LAN]`/`[DOMAIN]`/`[NO-UI]` 前缀，改用自然语言描述，顺序由 manifest 的 `order` 决定。`tags` 列保留在 manifest 供后续筛选，不参与渲染。
- **为什么 LDAP 目录不做 HTTP 探测**：LDAP 是 389 目录协议无 HTTP 端点，UI 侧经 ldapadmin 代理探测（description 已注明）；**真实 LDAP 校验在 `verify.sh` 的 `ldapsearch`**。
- **为什么 DNS 不做 HTTP 探测**：dnsmasq 是 53/udp，HTTP 探测恒红；卡片只用 ICMP 探测。T9 起 `ping` 目标由容器名 `dnsmasq` 改为**固定 IP `192.168.90.15`**（HomePage 容器内解析不到 `dnsmasq` 容器名会红卡，固定 IP 与其余 6 服务地址口径一致，不依赖容器名解析）；真实 DNS 校验仍用 `dig @192.168.90.15`。
- **自身卡探测用 localhost**：homepage 卡用 `http://localhost:3000/`，写域名会撞 `HOMEPAGE_ALLOWED_HOSTS`。

## 3. 动态注册（manifest 驱动，R2）
唯一真源 `services/manifest.tsv`（列：order/service/depends_on/health_url/monitor_url/ping_url/public_path/tags/ui_kind）。新增服务 = manifest 加一行 + 建 `services/<svc>/compose.yml`：
```
python3 scripts/render-homepage.py          # 渲染 config/homepage/services.yaml
python3 scripts/render-homepage.py --check  # 门禁：与 manifest 不一致返回非 0
```
生成物首行写死 `# GENERATED BY ... 禁止手改`；`up.sh` 启动 homepage 前自动渲染。未采用 Docker socket 方案（避免把宿主 Docker 控制权交给公网可达容器）。

## 4. 配置与外观
- `config/homepage/settings.yaml`：`startUrl: /`（不写 home，免 308）、`favicon: /favicon.ico`（真实文件，Dockerfile COPY，根治 404）、布局键 `服务状态`/`公网入口`（与 services.yaml 分组名一致，R6 改名）、无天气 widget（断网零裂图）。
- `HOMEPAGE_ALLOWED_HOSTS = ${PUBLIC_HOST},localhost,127.0.0.1`，无 `home.<domain>` 子域写法。
- `HOMEPAGE_VAR_PUBLIC_HOST` 由 compose 注入，取值 `${PUBLIC_HOST}`（遵循用户拍板：Funnel/ts.net 为默认）。

## 5. 图标与样式清单（T7）

所有静态资源均为仓库内真源、随镜像 `COPY`固化，**首页图标区零外链 CDN**（断网不裂图）。真源在 `config/homepage/`，由 `scripts/sync-build-context.sh` 同步到 `services/homepage/build/`，Dockerfile 从 `build/` `COPY` 进镜像。

| 文件（真源 `config/homepage/`） | 内容 | 镜像内落点 | 访问路径 | 来源 |
|---|---|---|---|---|
| `favicon.ico` | 真实 ICO，16x16 32bpp，1150 B | `/app/public/favicon.ico` | `/favicon.ico` | 仓库内置，`settings.yaml` 的 `favicon: /favicon.ico` 引用 |
| `custom.css` | 卡片圆角（`--of-card-radius: 12px`）+ 分组标题字号（`1.05rem`），非空 | `/app/config/custom.css` | `/api/config/custom.css` | 仓库内置最小可用样式 |
| `android-chrome-192x192.png` | PNG 192x192 RGBA，1514 B | `/app/public/android-chrome-192x192.png` | `/android-chrome-192x192.png` | 按官方 PWA manifest 实际请求名 |
| `android-chrome-512x512.png` | PNG 512x512 RGBA，4340 B | `/app/public/android-chrome-512x512.png` | `/android-chrome-512x512.png` | 同上（修复文档写 `512x192` 系笔误，按 manifest 实名，不改名） |
| `LICENSE` | SPDX 许可文本 | `/app/public/LICENSE` | `/LICENSE` | `licenses/MIT.txt` 等 |

> `bookmarks.yaml` 中的 `https://caddyserver.com/...` 等是用户点击才访问的**书签跳转链接**，非首页自动加载资源；`services.yaml` 的 `{{HOMEPAGE_VAR_PUBLIC_HOST}}` 是运行时注入占位符，均不属于外链 CDN 请求。

验收：`/favicon.ico`（image/*、>0B）、`/api/config/custom.css`（>0B）、两张 PWA 图标（200）须在 §10 步骤5 重建 homepage 后逐条 `curl -I` 确认。

## 6. 启动 / 健康检查 / 用例 / 排障
- 启动：`up.sh --only homepage`（独立命名空间），隔离端口 8082，固定 IP .11。
- 健康：`curl -H 'Host: localhost' http://127.0.0.1:3000/` → 200；`/favicon.ico` 200。
- 用例：`tests/bats/S_homepage.bats` + `tests/bats/15_homepage.bats`（全栈）；R6 后断言 **6/4 卡**（服务状态 6 + 公网入口 4）、href 全 https 无 `.local`、两分组名为「服务状态」/「公网入口」、无 `[lan][domain]/[NO-UI]` 前缀。
- 排障：卡片不显示 → 跑 `render-homepage.py --check` 看是否手改了生成物；裂图 → 确认无外链 CDN 图标；404 favicon → 确认镜像含 `/app/public/favicon.ico`。
