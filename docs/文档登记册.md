# 文档登记册

> 配置项清单（IEEE 828 §配置标识 / §状态纪实）。**这是文档体系的唯一权威清单**：
> 一篇文章在不在这里、什么状态、谁负责、什么时候该重看，全看这张表。
> 规则见 [文档规范](文档规范.md)，阅读入口见 [文档地图](文档地图.md)。
>
> 门禁：`python3 scripts/check_docs_meta.py`（`make docs-check`）。它硬查五件事 ——
> 磁盘与登记册双向一致、DOC-ID 唯一且合规、`approved` 必须有评审日期、
> `superseded` 必须指向替代者；复审超期只报 WARN，不阻断。

## 列的含义

| 列 | 含义 |
|---|---|
| `DOC-ID` | 永久编号，永不复用。改文件名不改编号 |
| `层级` | 入口 / 规程 / 参考 / 记录，判定见规范 §2 |
| `状态` | draft / review / approved / superseded / archived，含义见规范 §4 |
| `评审日期` | **该文档内容最后一次被接受的日期**。本表初建时取「该文件最后一次内容提交日期」，不臆造审批 |
| `复审(月)` | 到期只提示、不阻断；到期后由负责人决定续期 / 改写 / 退役 |
| `关联` | Issue 号，用于需求→设计的追溯 |
