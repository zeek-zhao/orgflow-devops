# 文档地图

从零构建的最小 DevOps 底座，7 个容器：dnsmasq → certs-init → caddy → ldap → ldapadmin → homepage → router。

## 按角色阅读

| 你是 | 先读 |
|---|---|
| 想了解整体 | [架构总览](架构.md) |
| 想部署/运维 | [使用说明](使用说明.md) |
| 想改某个服务 | `docs/services/` 下对应手册 |
| 想知道治理规则 | `docs/records/M0-治理约定.md`（T0 引入） |

## 目录

- `docs/架构.md`：组件、固定 IP、域名、启动顺序、降级策略
- `docs/使用说明.md`：从零部署、单服务启动、验收、客户端接入
- `docs/services/*.md`：7 份服务手册（六段结构：职责/配置/启动/健康/用例/故障）
- `docs/records/`：治理约定、变更台账、执行日志、人工验收单

## 门禁

- `make check`：快检查（记录/镜像/基底/文档/配置）
- `make verify`：全量验收矩阵（静态必过，行为项需真机）
