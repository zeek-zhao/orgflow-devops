# 公网访问（Tailscale Funnel + Caddy 唯一入口）

> 让公网用户通过一个 HTTPS 域名直接访问所有服务。配置标识 DOC-P-003。

## 设计原则

底座的**唯一 Web 入口是 Caddy**。公网不额外引入旁路网关，所有服务流量都经 Caddy 反代：

```
公网用户
   │ HTTPS（*.ts.net 合法证书）
   ▼
Tailscale Funnel（边缘终止 TLS）
   │ 明文 HTTP → 127.0.0.1:18081
   ▼
Caddy :18081（公网入口，按 path 路由）
   ├── /healthz /status        → Caddy 自身（存活探针）
   ├── /ldapadmin/*            → ldapadmin:80
   ├── /router/*               → router:8080
   └── /（兜底，含 /_next/*）   → homepage:3000（唯一门面）
   注：Caddy admin（:2019）只绑内网 IP，公网不可达，无 /caddy/* 路由。
```

底座 7 服务使用内部域名（`*.org-devops.local`）+ 内部 CA 自签证书，公网无法解析；而 Funnel 只提供**一个** `*.ts.net` 域名。Caddy 的公网入口站点（`:18081`，纯 HTTP，因 TLS 已在 Funnel 边缘终止）按 path 分发。HomePage 占根路径 `/`（唯一门面），其静态资源 `/_next/static/*`、`/api/*`、`/site.webmanifest` 随根路径一起命中，杜绝裂图。这是默认部署模式（internal + Funnel）；acme/自有域名直听 `:443` 为可选生产模式，详见 `engineering/证书与CA.md`。

## 入口

| 项 | 值 |
|---|---|
| 公网域名 | `https://orgflow-sandbox.tail0b7621.ts.net/` |
| 暴露方式 | `tailscale funnel --bg --yes 18081`（Funnel 边缘终止 TLS） |
| 本地目标 | `127.0.0.1:18081`（Caddy 公网入口，宿主端口映射 `${PUBLIC_PORT:-18081}:18081`） |
| 配置真源 | `config/Caddyfile`（公网入口 `:PUBLIC_PORT` 站点块）；router `/render` 可对实跑配置热更新 |

## 路径映射（全部经 Caddy）

| 公网路径 | 后端 | 说明 |
|---|---|---|
| `/` | `homepage:3000` | 统一导航面板（唯一门面，不 strip 路径） |
| `/_next/static/*` `/api/*` | `homepage:3000` | 随根路径命中，杜绝裂图 |
| `/healthz` `/status` | Caddy | 入口存活探针 |
| `/ldapadmin/` | `ldapadmin:80` | LDAP 管理页 |
| `/router/routes` `/router/healthz` | `router:8080` | 路由状态/热更新 |

> 安全收紧（P0）：Caddy admin（`:2019`）只绑内网 IP `192.168.90.10`，公网无法触达，**不再暴露 `/caddy/*`**。任何人不能从公网 POST `/load` 换掉反代配置。

`ldap`(389) 与 `dnsmasq`(53/udp) 非 HTTP 内部服务，不提供公网 Web 路径。

> 修复记录：原内网站点 `reverse_proxy home:3000` 指向了不存在的服务名 `home`（compose 服务名实为 `homepage`），导致 `home.org-devops.local` 一直 502。已在 entrypoint 中改为 `homepage:3000`。

## 运维命令

```bash
# 幂等恢复公网入口（推荐；已正确配置则跳过）
bash scripts/funnel-up.sh
# 手动开关
tailscale funnel --bg --yes 18081
tailscale funnel --https=443 off
# 自检
curl -s https://orgflow-sandbox.tail0b7621.ts.net/healthz
curl -s https://orgflow-sandbox.tail0b7621.ts.net/        # HomePage 门面
```

## 开机自启 / 持久化

- **容器**：全栈 compose 已给 6 个常驻服务加 `restart: unless-stopped`（certs-init 为一次性容器保持 `no`）。Docker daemon 重启后容器自动恢复。
- **Funnel**：是 tailscaled 的进程级配置，tailscaled/机器重启后需重新下发。用 `scripts/funnel-up.sh`（幂等）恢复。按环境选择固化方式：
  - cron（若有）：`@reboot sleep 20 && bash /path/to/scripts/funnel-up.sh >>/var/log/funnel.log 2>&1`
  - systemd unit（示例）：

    ```ini
    [Unit]
    Description=OrgFlow Funnel
    After=tailscaled.service docker.service
    [Service]
    Type=oneshot
    ExecStart=/bin/bash /path/to/scripts/funnel-up.sh
    [Install]
    WantedBy=multi-user.target
    ```

  - 本沙箱无 cron/systemd：重启后手动执行一次 `bash scripts/funnel-up.sh` 即可（约 1 秒）。
