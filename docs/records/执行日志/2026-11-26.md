- **真正原因**：`gerrit.config.tmpl` 用了错误的键 `bindDN`/`bindCredential`，Gerrit 3.9 忽略它们继续匿名 bind。官方文档正确键是 `ldap.username` + `ldap.password`，且须 `supportAnonymous=false` 才关闭默认匿名探测。secure.config 里的小写 `bindcredential` 是无效键且会缓存旧口令。
- **修复**（3 文件）：模板 `[ldap]` 改为 `supportAnonymous=false` + `username=cn=admin,dc=orgflow,dc=local` + `password=${LDAP_BIND_CREDENTIAL}`（占位符）；compose 注入 `LDAP_ADMIN_PASSWORD: ${LDAP_PASSWORD:-change-me}`；entrypoint 用 sed 渲染口令到卷内 gerrit.config（600/gerrit），删除写 secure.config 的无效逻辑。手工清理卷内 secure.config 的历史 ldap 段。
- `bash up.sh --recreate gerrit` 3 次迭代验证：前两次（bindDN/secure.config 与 bindDN/gerrit.config）均报 err=32；第三次（username/password/supportAnonymous）LDAP 日志见 Gerrit `BIND dn="cn=admin,..."` 成功。
