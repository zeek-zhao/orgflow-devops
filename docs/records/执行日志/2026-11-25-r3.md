## 3. 关键排障：JCasC 崩溃循环（本轮最大坑）

- 现象：首次用 `docker compose up --force-recreate` 直接重建（未经 up.sh）→ 容器每 ~10s 重启，日志只有 `Running from jenkins.war`，`failed-boot-attempts.txt` 累积 50+ 行。
- 根因链：直接 compose up **未注入 agent SSH 密钥/host key** → JCasC `sshHostKeyVerificationStrategy` 构造失败 → `ConfigurationAsCodeBootFailure` → JCasC 失败计数达阈值 → Jenkins 快速退出形成循环；`logging.properties`（空）又吞了 JVM 日志。
- 修复：清 `failed-boot-attempts.txt` → 用 up.sh（注入 `secrets/` 密钥）重建 → 干净启动。教训：**Jenkins 重建必须走 up.sh，禁止裸 `docker compose up`**（T9.1 的价值）。
- reload 通道：`POST /jenkins/configuration-as-code/reload`（不是 `/reload-configuration`，后者 404）；容器内 `localhost` + 同一 cookie jar 取 crumb 再 POST（分开取 crumb 会 CSRF 403）；CLI `-auth` 因 `Unexpected request origin` 不可用。
