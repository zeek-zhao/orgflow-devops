# 排障（DOC-08）

> 按现象索引，每条「现象 → 定位 → 处置」。详细历史见 records/问题解决方案记录.md。

| 现象 | 定位 | 处置 |
|---|---|---|
| 公网全 502 | Funnel 状态 / 安全组 | `tailscale funnel status`；放行 80/443 |
| 域名不解析 | `dig @127.0.0.1 -p 5353` | 查 dnsmasq GATEWAY_IP；hosts 兜底 |
| 站点 502 | `curl :2019/config/` | upstream 服务名写错（homepage≠home） |
| 证书告警 | 证书 SAN/CN | internal 模式装根证书；见证书与CA.md |
| ldap unhealthy | `docker logs of-ldap` | osixia chown 只读 LDIF → `--copy-service` |
| ldapadmin unhealthy | 302 循环 | 探针 `follow_location=0` + `$$` 转义 |
| 容器起不来 | `bash status.sh` | 看 exited 码；对照服务手册 |
| 磁盘满拉取失败 | `df -h /var/lib/docker` | vfs 孤儿层：删未被 cache-id/mount-id 引用的层 |
| GitHub push 502/超时 | 网络 | HTTP/1.1 + Basic auth（scripts/git-push.sh） |
| 路由改了不生效 | router /routes | 查 /render 返回；30s 轮询；Caddy admin |
| 文档门禁红 | `bash scripts/check-docs.sh` | 未登记文档补进 docs/README.md 附录登记表 |
| 域名门禁红 | `bash scripts/check-domain.sh` | 配置文件写死域名 → 改占位符 |
