# 路由注册（DOC-05）

## routes.yaml 字段

```yaml
routes:
  - host: home          # 子域，渲染时拼 GATEWAY_DOMAIN（来自 .env 的 DOMAIN）
    upstream: homepage:3000   # compose 服务名 + 端口，不走网关
```

- `host`：子域（不含点）时自动拼 `GATEWAY_DOMAIN`；写完整域名（含点）向后兼容。
- `upstream`：必须 `service:port` 格式，否则 422 拒绝 reload。

## 渲染流程

1. 改 `config/routes.yaml`（真源）。
2. `make routes` → 调 router `POST /render`。
3. router：读 routes.yaml → 校验 host/upstream → 渲染 Caddyfile 片段 → 调 Caddy admin `/load`。
4. 30 秒内新域名 200；与上次相同则幂等跳过 reload。

## 热更新端点

| 端点 | 方法 | 说明 |
|---|---|---|
| /healthz | GET | 存活 |
| /routes | GET | 当前渲染配置（断言用） |
| /render | POST | 校验+渲染+reload；坏 upstream 422 且不 reload；Caddy 不可达 503 降级 |

## reload 失败排查

- 422：routes.yaml 有非法 host/upstream → 看响应体错误说明。
- 503：Caddy admin（:2019）不可达，配置未加载 → 查 caddy 容器。
- 200 但域名不通：查 dnsmasq 是否解析新子域、证书 SAN 是否覆盖。
