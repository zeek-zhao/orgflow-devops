# 使用说明（DOC-07）

## 登录

| 项 | 值 |
|---|---|
| LDAP 管理页 | `https://ldapadmin.DOMAIN/` |
| 管理员 DN | `cn=admin,dc=orgflow,dc=local` |
| 管理员口令 | `.env` 的 `LDAP_PASSWORD` |
| 初始用户 | svc-platform-admin、zeek.zhao（仅 M0 现有服务所需） |

## 部署

```bash
cp .env.example .env && vim .env    # 改 DOMAIN（= GATEWAY_DOMAIN）
make render && make check && make up && make verify
```

## 加路由

```bash
vim config/routes.yaml              # 加一条 {host, upstream}
make routes                         # 30s 内生效
curl -H "Host: new.DOMAIN" https://.../  # 验证
```

## 改域名（AC-22）

只改 `.env` 的 `DOMAIN` → `make up` → dnsmasq 通配、Caddy 站点、router 子域、homepage 白名单/卡片、证书 SAN 全链路跟随，不改任何配置文件（`check-domain.sh` 保证无写死域名）。

每节验证命令见对应服务手册 `docs/services/*.md`。
