## 1. 配置项识别

| 配置项 | 真本路径 | 谁生成 / 谁改 | 锁定方式 |
|---|---|---|---|
| 路由模型 | `config/routes.yaml` | 人工 + 路由注册 API | `make render` 生成 `out/Caddyfile` |
| Jenkins 配置 | `config/jenkins.yaml` | JCasC | 重启生效；属性名以插件实际为准（#116 `includeRegex`） |
| Job 定义 | `config/job_definitions/*.yaml` | JJB | `make jobs` 推送 |
| 面板配置 | `config/homepage/*.yaml` | 人工 | 服务读取 |
| 编排 | `docker-compose.yml`、`docker-compose.ghcr.yml` | 人工 | `USE_GHCR=1` 默认拉取 |
| 镜像 digest | `tests/images.lock`、`docker-compose.ghcr.yml` 的 `# pinned-at:` | `make images-pin` | `@sha256:` |
| 工作流 | `.github/workflows/*` | 人工 | `uses:` 按 SHA 钉死 |
| 标签集合 | `.github/labels.json` | `make labels-sync` | `make test` 校验自洽 |
| 文档清单 | `docs/文档登记册.md` | 人工 | `make docs-check` 双向一致 |
| 环境真值 | 部署机 `.env` | 人工 | **不入库**，仓库只存占位符 |
| 渲染产物 | `out/` | `make render` / `make sbom` / `make cve` | 不入库，不手工删目录 |

`out/` 目录不能 `rm -rf`：router 与 caddy 把它作为 bind mount，删掉换 inode 后
容器仍持有被删除的旧 inode，watch 会一直报 ENOENT 却永远不恢复（#117 真机事故），
且 `out/ca/` 里是网关根证书。只删渲染产物，保留目录本身与 CA。

## 2. 基线

一次基线 = 一个提交 + 一组 digest + 一份 SBOM + 一份登记册状态。四条必须同时可查：

```bash
git rev-parse HEAD
grep -c '@sha256:' docker-compose.ghcr.yml
make sbom
make docs-check
```

基线不是「某天打包了一份」，是**任何时刻都能用上面四条命令复算出来的集合**。

## 3. 配置控制

任何配置变更走同一套（[项目管理](../项目管理.md) §9）：

1. 影响分析：波及哪些配置项、哪些门禁期望值、哪些文档。
2. 同一条 PR 改完配置 + 测试 + 文档 + 登记册（[文档规范](../文档规范.md) §6）。
3. 贴反证：改坏一处门禁必须红，恢复必须绿。
4. 架构性变更顺序：ADR → 服务手册 → 入口索引。

`scripts/check-image-source.sh` 的三条判据（digest 全锁定、`# pinned-at:` 可解析且提交在本地、
镜像上下文自 pinned-at 无改动）是配置控制在镜像侧的现成机制，改 Dockerfile 必红。

## 4. 状态纪实

| 想知道 | 命令 |
|---|---|
| 当前基线是哪个提交 | `git log --oneline -1` |
| 镜像有没有落后源码 | `make images-guard` |
| 文档状态与见证 | `make docs-check` |
| 提交身份是否唯一 | `make identity-check` |
| 公开面是否干净 | `make redaction` |
| 标签集合是否自洽 | `make test` |

状态不写进文档快照 —— 快照会过期，冲突时以代码与 `config/` 为准
（[文档地图](../文档地图.md)）。

## 5. 配置审计

| 审计项 | 命令 | 判据 |
|---|---|---|
| 文档双向一致 | `make docs-check` | 0 未登记、0 指向不存在 |
| 链接自洽 | `make links` | 0 悬空链接 |
| 脱敏 | `make redaction` | 0 命中 |
| 镜像来源 | `make images-guard` | 无「已提交未构建」 |
| 供应链 | `make check` | Action 全钉死、插件许可证齐 |
| SBOM 完整 | `make sbom` | `out/sbom.spdx.json` 覆盖全部分发镜像 |
