## 3. 双仓时代已关闭的缺口（不再有导出这一步，仅留追溯）

单仓化之后不存在「导出发布物」这个环节，下表是当时那个环节修掉的缺陷。**它们的判据已无对象**，
保留是因为这些坑在单仓形态下换了位置又出现过一次（例如「清单写两处、改一处忘另一处」）。

| 缺口 | 处置 | 反证 |
|---|---|---|
| 导出丢文件 | 导出脚本遍历全部参数 + 末尾做必需文件冒烟 | 移走 NOTICES → 报「发布物缺文件」+ rc=1 |
| GHCR 引用被脱敏规则改坏 | 删掉 `s/owner/your-org/g` 那类规则 | 导出物里 13 处真实引用、`your-org` 命中 0 |
| copyleft 义务 | NOTICES + `licenses/` 六份全文 + 源码指引 + 镜像 license 标签 | `make mirror` + 导出物 `licenses/` 七文件 |
| LICENSE 署名 | `Copyright 2026 zeek-zhao` | `LICENSE:190` |
| 构建产物入库 | `.gitignore` 覆盖 `.env`、导出清 `__pycache__` | 导出物零 pyc |
| 无 SBOM / 无 CVE | `make sbom`（SPDX）+ `make cve`（trivy，先出账不阻断） | `out/sbom.spdx.json` |
| 导出死链 11 条 | 悬空链接降级为纯文本 + 校验必须 0 | 加一条假链接 → rc=1 |
| SECURITY 链接 404 | 不再脱敏 owner，链接保留并可解析 | `SECURITY.md:8` |
| 密钥扫描只扫工作区 | 公开仓 `--log-opts=--all` 扫全历史 | `.github/workflows/secret-scan.yml` |
