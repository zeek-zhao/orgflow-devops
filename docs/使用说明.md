# 使用说明

> 状态：适用 | 最后核对：2026-11-24 | 对应分支：feat/m0-v2


## 前置

- Docker 27+ 与 Compose v2、openssl、python3
- 沙箱/离线环境无法拉取镜像时，行为验收留到联网真机环境

## 从零部署

```bash
make doctor              # 只读环境自检
make render              # 渲染配置产物（含 HomePage services.yaml）
make check               # 快检查（无 docker）
make up                  # 按 manifest 顺序逐服务起，就绪断言，失败中止
make status              # 只读查看各容器健康
```

## 单服务启动（零依赖）

```bash
make up-dnsmasq          # 只起 dnsmasq（隔离端口，不占 80/443）
make test-dnsmasq        # 跑 S_dnsmasq 用例
make down-dnsmasq
# 对 7 个服务逐一执行即可验证 REQ-MIN-11
```

## 登录

| 项 | 值 |
|---|---|
| 统一面板（公网） | `https://PUBLIC_HOST/`（Tailscale Funnel，根路径即 HomePage） |
| LDAP 管理（公网） | `https://PUBLIC_HOST/ldapadmin/` |
| 路由状态（公网） | `https://PUBLIC_HOST/router/healthz` |
| LDAP 管理（内网） | `https://ldapadmin.DOMAIN/` |
| 管理员 DN | `cn=admin,dc=orgflow,dc=local` |
| 管理员口令 | `.env` 的 `LDAP_PASSWORD` |
| 初始用户 | svc-platform-admin、zeek.zhao（仅 M0 现有服务所需） |

## 路由热更新

```bash
vim config/routes.yaml              # 加一条 {prefix, upstream}（路径型）
make routes                         # → router /render → Caddy reload（30s 内生效，不重启 Caddy）
```

> 唯一真源：`config/routes.yaml` 定义路径前缀；`config/Caddyfile` 是 caddy 容器启动挂载的静态配置（含 admin 绑定、内网 TLS 站点、公网 handle）。两者职责不同：routes 驱动热更新，Caddyfile 驱动启动，改路由只需改 routes.yaml。

## 改域名（AC-22）

只改 `.env` 的 `DOMAIN`（= `GATEWAY_DOMAIN`）→ `make up` → dnsmasq 通配、Caddy 站点、router 路径、homepage 白名单/卡片、证书 SAN 全链路跟随，不改任何配置文件（`check-domain.sh` 保证无写死业务网关域名）。公网入口域名单独由 `config/defaults.env` 的 `PUBLIC_HOST` 注入。

## 证书客户端接入

```bash
make ca                  # 导出根证书
# 客户端：安装根证书 + 配置 hosts（make hosts 生成片段）
```

## 验收

```bash
make verify              # 静态项必过；行为项标 NEEDS-ENV
make check-all           # 镜像 digest + 基底全量门禁
```

行为验收（DNS/证书/唯一入口/LDAP/路由/Tailscale/7 单起）需在真机按 `tests/bats/S_*.bats` 逐条跑，结果填入 `docs/records/M0-人工验收单.md`。

## 约定

- 唯一人工配置：`config/defaults.env`（非敏感默认）+ `.env`（敏感，不入库）
- 镜像只从 digest 引用；改镜像上下文后须 `make images-lock` 回填
- 一功能 = 一 Issue = 一 PR = 合并即关单；全程 `make record` 留痕
