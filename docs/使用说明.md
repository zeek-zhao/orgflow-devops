# 使用说明

## 前置

- Docker 27+ 与 Compose v2、openssl、python3
- 沙箱/离线环境无法拉取镜像时，行为验收留到联网真机环境

## 从零部署

```bash
make doctor              # 只读环境自检
make render              # 渲染 config/defaults.env → out/runtime.env
make check               # 快检查（无 docker）
make up                  # 按序起 7 容器，就绪断言，失败中止
```

## 单服务启动（零依赖）

```bash
make up-dnsmasq          # 只起 dnsmasq（隔离端口，不占 80/443）
make test-dnsmasq        # 跑 S_dnsmasq 用例
make down-dnsmasq
# 对 7 个服务逐一执行即可验证 REQ-MIN-11
```

## 路由热更新

```bash
# 改 config/routes.yaml
make routes              # → router /render → Caddy reload（30s 内生效，不重启 Caddy）
```

## 证书客户端接入

```bash
make ca                  # 导出 out/ca 根证书
# 客户端：安装根证书 + 配置 hosts（make hosts 生成片段）
```

## 验收

```bash
make verify              # 静态项必过；行为项标 NEEDS-ENV
make check-all           # 镜像 digest + 基底全量门禁
```

行为验收（DNS/证书/唯一入口/LDAP/路由/Tailscale/7 单起）需在真机按 `tests/bats/S_*.bats` 逐条跑，结果填入 `docs/records/M0-人工验收单.md`。

## 约定

- 唯一人工配置：`config/defaults.env`；敏感值走 `.env`（不入库）
- 镜像只从 digest 引用；改镜像上下文后须 `make images-lock` 回填
- 一功能 = 一 Issue = 一 PR = 合并即关单；全程 `make record` 留痕
