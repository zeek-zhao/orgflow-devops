# 架构总览

## 一句话

一台云主机上用 Docker Compose 起 7 个容器：DNS 解析 → 证书签发 → Caddy 唯一入口 → OpenLDAP 身份 → LDAP Admin → HomePage 面板 → 路由注册。所有镜像 `ubuntu:24.04@sha256` 基底 + digest 锁定。

## 组件表

| # | 组件 | 容器 | 职责 | 长驻 | 零依赖可起 |
|---|---|---|---|---|---|
| 1 | DNS | dnsmasq | `*.DOMAIN → .10` | 是 | 是 |
| 2 | 证书 | certs-init | 内部 CA + 站点证书 | 否(exit 0) | 是 |
| 3 | 入口 | caddy | `:80→308/:443` 唯一入口 | 是 | 是(bootstrap) |
| 4 | 身份 | ldap | OpenLDAP 目录 | 是 | 是 |
| 5 | 管理 | ldapadmin | LDAP Admin Web | 是 | 是(降级登录页) |
| 6 | 面板 | homepage | `home.<DOMAIN>` 一屏 | 是 | 是(纯静态) |
| 7 | 路由 | router | `routes.yaml→reload` | 是 | 是(503 降级) |

## 域名与固定 IP（192.168.90.0/24）

| 域名 | 后端 | IP |
|---|---|---|
| home.<DOMAIN> | homepage:3000 | .11 |
| ldapadmin.<DOMAIN> | ldapadmin:8080 | .12 |
| auth.<DOMAIN> | ldap:389（探活） | .13 |
| router.<DOMAIN> | router:8080 | .14 |
| — | caddy（入口） | .10 |
| — | dnsmasq（DNS） | .15 |

## 启动顺序与就绪判据

1. dnsmasq（无前置）→ dig 返回 .10
2. certs-init（无前置）→ exit 0 且卷内有 CA + 证书
3. ldap（无前置）→ ldapsearch 成功
4. caddy（前置 certs-init）→ Admin API 200；未就绪报 **D003** 并中止
5. homepage（前置 caddy）→ :3000 可连
6. ldapadmin（前置 ldap,caddy）→ :8080 可连
7. router（前置 caddy,homepage,ldapadmin）→ /healthz 200

## 降级策略（缺邻居不崩）

- caddy 无证书 → 生成 bootstrap 自签占位
- ldapadmin 连不上 ldap → 显示登录页并重试
- router 连不上 caddy → `/render` 返回 503 而非 exit

## 证书设计

- CA 10 年 / 站点 825 天，`make ca-rotate` 轮换
- SAN 覆盖 `*.<DOMAIN>` + 各子域 + apex
- `make ca` 导出根证书，客户端手工安装
- 幂等：已存在且未过期跳过，`FORCE=1` 才重签
