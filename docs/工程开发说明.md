# 工程开发说明

> **读者**：要改这个仓库的人（以及替他改代码的 AI）。
> **管什么**：目录语义、本地怎么起、改一条 X 要动哪几个文件、坏了自己怎么定位。
> **不管什么**：怎么提交/合并 → [CONTRIBUTING](../CONTRIBUTING.md)；要求与验收判据 → [requirements/](requirements/README.md)；
> 某一类操作的使用姿势 → [使用说明](使用说明.md)。

## 1. 目录语义（只看这一张表就够）

| 路径 | 是什么 | 改它的后果 |
|---|---|---|
| `config/routes.yaml` | **路由真源**：子域 → 上游 → 是否要登录 | 改完 `router` 自动重渲染 `out/Caddyfile` 并热重载，**不重启容器** |
| `config/jenkins.yaml` | Jenkins JCasC（realm / 授权 / 凭据 / 节点 / 视图） | 改完重启 `jenkins`；写错会让 Jenkins 启动中断 |
| `config/job_definitions/*.yaml` | Job DSL 定义，由 JJB 推进 Jenkins | 改完跑 `make jobs`；job 参数校验比手点可靠 |
| `config/homepage/` | 入口面板的卡片与书签 | 每个书签必须有 `href`，缺了整页报 Invalid URL（[homepage](services/homepage.md)） |
| `services/router/` | Caddyfile 渲染器（python） | 渲染逻辑改动必须补 `services/router/test_render.py` 用例 |
| `services/auth/` | LDAP 初始数据（ldif）、Dex 模板、bootstrap 脚本 | `ldif` 里只有 `{SSHA}` 哈希；口令我同步见 [ldap](services/ldap.md) |
| `services/jenkins/`、`services/dnsmasq/` | 这两个是**镜像构建上下文**（Dockerfile + 静态资源） | 改完必须走 CI 构建 + `make images-pin`，不能只改本地 |
| `tools/jjb`、`tools/jenkins-agent` | 另外两个镜像上下文 | 同上 |
| `tests/bats/` | 全栈行为断言，DinD 里跑（用例数以 `bats --count` 为准） | 加断言优先于加脚本 |
| `tests/harness/` | DinD 运行器：起 stack → bootstrap → 跑 bats | 测试环境的「一次性动作」都放这里 |
| `tests/images.lock` | 镜像 digest 锁 | 只能由 `make images-lock` 生成，不手改 |
| `scripts/` | 运维脚本（deploy / backup / restore / 各种门禁） | 脚本的期望值必须与架构变更一起改，否则自检永远红 |
| `out/` | **全部产物**（Caddyfile、dex 配置、CA、备份、SBOM） | gitignore，可随时 `make clean`；别手改，改了会被覆盖 |
| `docs/` | 文档，受登记册管辖 | 新增/删除必须同步 `docs/文档登记册.md` |

## 2. 本地起一套（含 DinD 测试）

```bash
cp .env.example .env          # deploy 会随机填充密钥；手动起也要先有这个文件
docker compose up -d          # 或用 make deploy（带前置闸门与逐服务健康检查）
docker compose ps             # 全是 healthy 只是底线，不代表可用
```

不需要 docker 的自检（提交前必跑）：

```bash
make check                    # 快检查：文档配置 / 死链 / 脱敏 / 标签清单（几秒）
make test                     # 静态断言 + 行为测试，秒级
make docs-check links redaction   # 需要单跑某一项时
```

两个钩子与这两层一一对应：`pre-commit` 跑 `make check`，`pre-push` 跑 `make check-all`。
分层不是偷懒：把重的塞进 `pre-commit` 的结局是「每次都 `--no-verify`」，等于没有钩子。

需要 docker 的全栈行为验证：

```bash
make test-bats                # 在 DinD 里起 10 个服务 + 部署 nexus，再跑全部 bats 断言
KEEP=1 make test-bats         # 保留现场，失败后进去看
```

> `make test-bats` 只测**本地构建**的镜像（`TEST_BATS_GHCR` 缺省 0）。用 GHCR 镜像跑 bats 等于测上一个提交，
> 是典型的自欺，所以这条不跟随 `USE_GHCR`。

## 3. 改一条 X：动哪几个文件

| 想做的事 | 必改 | 连带 |
|---|---|---|
| 加一个站点 | `config/routes.yaml` | 该服务的 compose 段（端口/expose）、bats 里加一条「放行 + 拒绝」 |
| 给站点加登录 | `config/routes.yaml` 的 `auth: true` | oauth2-proxy 的 `allowed-group`；检查 bats 的 ACL 用例 |
| 加一个容器服务 | `docker-compose.yml` + `tests/images.lock` | `docs/services/<svc>.md`（六段式）、`docs/network/arch.md` 的 IP 表、备份脚本的服务白名单 |
| 改 Jenkins 配置 | `config/jenkins.yaml` | 重启 jenkins；`23_jenkins_agent.bats` / `16_jenkins.bats` 可能跟着变 |
| 加一个 job | `config/job_definitions/` | `make jobs` 推上去，`scripts/test_jobs.py` 校验参数与断言 |
| 改 Dockerfile | `services/*/Dockerfile` | CI 构建 → `make images-pin` → commit；不能用本地构建顶替 |
| 改门禁规则 | `scripts/check_*.py|sh` | 必须同时给**反证**（改坏一处必须红），否则等于关掉了门禁 |
| 加一篇文档 | `docs/*.md` | `docs/文档登记册.md` 加一行（DOC-ID / 层级 / 状态 / 复审），`docs/文档地图.md` 加入口 |

## 4. 定位问题的入口（别从 `docker ps` 开始猜）

| 现象 | 第一跳 |
|---|---|
| 站点 502 / 000 / 证书告警 | `docs/network/arch.md` 的分层决策树（逐层打穿，不跳层） |
| 登录循环 / 403 | [oauth2-proxy](services/oauth2-proxy.md)：它**没有** API 旁路开关，API 校验要走容器内直连 |
| Jenkins job pending | [jenkins](services/jenkins.md) + [jenkins-agent](services/jenkins-agent.md)：`healthy ≠ 能干活` |
| LDAP bind 返回 49 | `.env` 的口令与目录里的不一致；`make ldap-apply`（改 LDIF 对已存在条目无效） |
| 改了路由没生效 | `out/Caddyfile` 是产物；看 `router` 日志有没有 reload，别去改 Caddyfile |

三个通用手法：

```bash
docker compose logs --tail=50 <svc>          # 先看日志，再看代码
docker compose exec -T <svc> <cmd>           # 在容器里验证「进程内视角」
curl -sSk --resolve <sub>.org-devops.com:8443:127.0.0.1 https://<sub>.org-devops.com:8443/ -I
```

最后一条是这套栈最常用的断言姿势：**用域名 + SNI 打本机端口**，不依赖 hosts 与 DNS，
所以它测的是 Caddy 的站点匹配，而不是「我的浏览器缓存」。

## 5. 这套栈的五个坑（都真踩过）

1. **`Path.write_text()` 在 Windows 上会写 CRLF**，把带 `set -o pipefail` 的脚本变成语法错误 → 写脚本一律按 `.gitattributes` 归一换行。
2. **耗时门禁在 Windows 上被杀 = 假红**。假红比没有门禁更贵：它训练人忽略红灯。宁可分层跑，也不要让门禁「有时红」。
3. **`grep` 的规则以 `-` 开头会被当选项**，整条规则静默失效（私钥块规则就这么失效过）。写规则时加 `--`。
4. **POSIX ERE 里没有 `\d`**。写成 `\d` 的网段规则会静默放行，看起来一切正常。
5. **容器必须同时挂 `/etc/passwd` 与 `/etc/group`**。sstatesig 用 `grp.getgrgid()`，只挂一个会报找不到组。

## 6. 改完的自检清单

```
[ ] 找得到对应需求号（docs/requirements/），或明确写了 N/A 的理由
[ ] make test / docs-check / links / redaction 全绿
[ ] 动了运行时行为 -> make test-bats 绿，且新增断言有反证
[ ] 动了镜像上下文 -> CI 构建完 + make images-pin 已提交
[ ] 新增/删除文档 -> 登记册与文档地图同步
[ ] 门禁或期望值跟着变了 -> 说明写进 PR 正文
```
