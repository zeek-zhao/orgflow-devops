## 2. 容量报告（只读）

```bash
make disk-report
```

输出：磁盘水位、Docker 空间概览、在用镜像 tag（不可清理）、dangling 镜像（可清理）、非在用 tag 候选（需人工确认）、旧构建数、artifacts/backups 大小。

## 3. 清理

```bash
make prune-images            # dry-run，仅列出将删除的 dangling 镜像
CONFIRM=1 make prune-images  # 实际执行 docker image prune -f（仅 dangling，不动在用 tag）
```

- 只清 dangling 镜像（`docker image prune -f`），不用 `prune -a`，保留在用 tag 与最近版本。
- 非在用 tag 镜像仅列为候选，**不自动删**（很多是 M2 历史构建的 GHCR 中转镜像，删前人工确认是否需要回滚）。
- 备份目录轮转：`/data/backups/<UTC>/` 保留策略日备 7 份、周备 4 份；超期目录人工确认后删除（脚本不自动删备份）。
- Jenkins 旧构建：由各 Job 的 logRotator 管理（heavy 项 7 天/20 次）；不手动批量删。

## 4. 注意事项

- 清理前确认无正在进行的构建/重建演练；演练窗口内不做清理。
- `artifacts/quota` 由 `quota-guard-loop.sh` 每轮自轮转（cron.log >1MB），一般无需干预。
- 镜像清理只回收 dangling 层；如要回收"非在用 tag"，须先确认无回滚需求，再 `docker rmi <image>` 逐个删。
- 每次实际清理记录回收量到执行日志（本次演练回收 97.23MB，见备份与恢复 §6.5）。
