# 安全基线（公网暴露面）

> 状态：适用 | 最后核对：2026-11-24 | 对应分支：feat/m0-release（R8）

M0 单机底座对公网只开放**一个入口**：Tailscale Funnel → Caddy `:PUBLIC_PORT`。本文件记录每一层的最小暴露面与已落地的收口措施，作为部署后自检清单。

## 1. 公网暴露面（唯一入口）

| 层 | 绑定/暴露 | 说明 |
|---|---|---|
| Tailscale Funnel | 公网 HTTPS 边缘，回源 `:PUBLIC_PORT`（默认 18081） | **唯一公网入口**；边缘终止 TLS，明文回源到本机 Caddy |
| Caddy `:PUBLIC_PORT` | 只处理路径反代 | 公网 Host 为 `PUBLIC_HOST`；无子域 vhost |
| Caddy admin `:2019` | **仅内网**（127.0.0.1 / 容器网段） | 不对外；公网 `/caddy/*` 无路由 |
| LDAP `389` | **不出网** | 仅容器网内；无宿主端口映射到公网 |
| dnsmasq `53/5353` | 仅容器网内 | 无宿主公网映射 |

> 判定：公网可达 = 只有 Funnel 边缘那一个域名 + 端口；其它端口一律不暴露到公网网卡。核对命令见 §4。

## 2. 已落地的收口（R1，2026-11-24）

| 项 | 措施 | 公网实测 |
|---|---|---|
| `/api/services`、`/api/widgets` | Caddy Host 判定：公网 host 返回 403，仅内网 host/容器 IP 反代到 homepage | 403 ✓（不再泄漏内网 IP/宿主指标） |
| `POST /router/render` | Caddy `handle @render` 公网 403 | 403 ✓ |
| `/router/` | 308 → `/router/healthz` | 308 ✓ |
| `/ldapadmin/`、`/home`、`/caddy/config` | 路径归一 308 | 308 ✓ |
| `/healthz`、`/status`、`/` | 正常开放 | 200 ✓ |

> 判定用 **Host** 而非 remote_ip：公网经 Funnel、容器内经 docker 网桥，两者 `.remote.host` 同为网关 IP，remote_ip 方案实测失效；Funnel 保留原始 Host，故用 Host 判定。已知边界：`curl` 可伪造 Host 绕过（浏览器不可），此为 Funnel 回源架构固有约束。

## 3. 认证与凭据

- LDAP 管理页（phpLDAPadmin）需登录；管理员口令来自 `.env` 的 `LDAP_ADMIN_PASSWORD`，`.env` 不入 git。
- HomePage `HOMEPAGE_ALLOWED_HOSTS = ${PUBLIC_HOST},localhost,127.0.0.1`，无 `home.<domain>` 子域写法；防 Host 头注入。
- 内部 CA 私钥在 `orgflow-minimal_ca-data` 卷，不外泄；备份按 [备份与恢复](备份与恢复.md)。

## 4. 部署后自检清单

```bash
PH="$(grep '^PUBLIC_HOST=' config/defaults.env | cut -d= -f2-)"
PP="$(grep '^PUBLIC_PORT=' config/defaults.env | cut -d= -f2-)"
for p in / /healthz /status /api/services /api/widgets /router/ /router/render; do
  printf '%-20s ' "$p"
  curl -s -o /dev/null -w '%{http_code}\n' -H "Host: $PH" "http://127.0.0.1:${PP:-18081}$p"
done
# 期望：/ /healthz /status = 200；/api/services /api/widgets = 403；/router/ = 308；render(GET) 视 Caddy 规则
```

**判定标准**：

- `/api/services`、`/api/widgets` 对公网 Host 必须 403；若为 200，说明 R1 收口未生效，立即停公网入口排查。
- 宿主 `ss -tlnp` 不应看到 `389`、`5353` 绑在 `0.0.0.0`；Caddy `:2019` 只绑内网地址。
- 6 个容器全 healthy：`bash status.sh`。

## 5. 已知残留（如实记录）

- HomePage SSR HTML 的 `__NEXT_DATA__` fallback 仍可能内嵌内网 IP（R1 只收口了两个 JSON API，未覆盖 SSR 内嵌数据）。公网首屏 HTML 中若出现内网 IP，属于信息残留但不影响功能；彻底清除需改 HomePage 渲染层，属后续增强项。
- Host 判定可被 `curl -H` 伪造（浏览器不可），为 Funnel 回源架构固有边界。
