# 构建资源配额（M2.5 P0 / m2.5.1 生命周期加固）

## 1. 铁律（对实施/构建 Agent 的强制约束）

每次启动构建容器前必须记录四项，缺一项即 BLOCKED，不得继续构建、不得写成 `full-quota PASS`、不得回写 Verified：

1. `nproc`
2. `/proc/meminfo` 的 `MemTotal`（kB）
3. `docker info --format 'NCPU={{.NCPU}} MemTotal={{.MemTotal}}'`
4. `docker inspect <容器> --format 'NanoCpus={{.HostConfig.NanoCpus}} Memory={{.HostConfig.Memory}} CpuQuota={{.HostConfig.CpuQuota}}'`

四项必须显示宿主全部资源，且目标容器 `NanoCpus=0`、`Memory=0`、`CpuQuota=0`。

### 判据（脚本内置）

| # | 断言 | 说明 |
|---|---|---|
| 1 | `docker info` 的 `NCPU == nproc` | 精确相等，不是"接近" |
| 2 | `docker info` 的 `MemTotal == /proc/meminfo MemTotal(kB)×1024` | 允许 ≤1% 测量偏差，偏差值必须打印；超过 BLOCKED |
| 3 | `docker inspect NanoCpus=0` | 精确 0 |
| 4 | `docker inspect Memory=0` | 精确 0 |
| 5 | `docker inspect CpuQuota=0` | 精确 0 |
| 6 | 四项落盘成证据文件 | 无文件 = BLOCKED，不接受"日志里有" |
| 7 | 启动前后宿主三项一致（P2-1） | `--preflight` 快照与启动后采集比对，不一致 BLOCKED |

**新鲜度（≤10 分钟）属消费端职责**：脚本只写 `ts`，不自判新鲜度（m2.5.1 P1-2 删除了半成品 `--max-age-min`）。判新鲜度在 `build-from-gerrit` 的 Quota gate（严格 FAIL）与 `verify-quota-guard`（WARN 提示）两处完成。

**禁止项**：任一缺失/命令失败/容器不存在/启动前后宿主变化/数值不匹配 → verdict 只能是 `BLOCKED`；不得写 `PASS` 或 `full-quota PASS`，不得继续 `buildctl build`，不得回写 Verified。

## 2. 脚本用法

```bash
# 完整取证（默认，门禁消费）
bash scripts/quota-guard.sh --container of-builder --out artifacts/quota
# 启动前宿主预检（只查宿主三项，docker 被限权即 BLOCKED）
bash scripts/quota-guard.sh --container of-builder --out artifacts/quota --preflight
# 启动后取证并与预检快照比对
bash scripts/quota-guard.sh --container of-builder --out artifacts/quota --compare-preflight artifacts/quota/host-preflight.json
# 退出码：0=PASS  2=BLOCKED(缺项/不匹配)  3=环境不可用(docker 不可达/容器不存在)
```

stdout 固定四行（便于 CI 日志 grep，`--preflight` 只打前三行）：

```
[quota] nproc=5
[quota] MemTotal=8570968 kB
[quota] docker info NCPU=5 MemTotal=8776671232
[quota] inspect NanoCpus=0 Memory=0 CpuQuota=0
[quota] verdict=PASS reason=none
```

### 证据文件（m2.5.1 P1-1：按容器名隔离）

| 文件 | 用途 | 是否参与门禁 |
|---|---|---|
| `latest-of-builder.json` | **门禁消费端固定读此文件** | ✅ 是 |
| `latest.json` | 最后写入者的人类查看副本 | ❌ 否 |
| `<UTC>-<container>.json` | 历史快照，用于审计 | ❌ 否 |
| `host-preflight.json` | 启动前宿主三项快照，供比对 | ❌ 否 |

按容器名隔离后，单服务重建 `up.sh --only jenkins-agent` 只会写 `latest-of-jenkins-agent.json`，**不会覆盖 `latest-of-builder.json`**，Quota gate 仍可 PASS——不再需要"记得重跑一次 builder"。

`make quota-guard` 是等价入口（需 docker）；`bash scripts/quota-status.sh` / `make quota-status` 查看证据 ts/age。

## 3. 三处接入点（缺一处等于没做）

1. **up.sh（P2-1 两段式）**：`builder` / `jenkins-agent` 启动**前**先跑 `--preflight` 采集宿主三项并校验 docker 未被限权，任一项不满足 → 立即 BLOCKED 非 0 退出，绝不带病启动容器；`compose up` 成功后再跑 `--compare-preflight` 完整取证并与前置快照比对，落 `latest-of-builder.json`；任一项不满足 → BLOCKED 非 0 中止，不再启动后续服务。
2. **build-from-gerrit Pipeline**：`Checkout change` 之前新增 `stage('Quota gate')`，只读 `/opt/orgflow/quota/latest-of-builder.json`（repo 的 `artifacts/quota` 只读挂进 controller 与 agent），断言 `verdict==PASS`、`container==of-builder`、`ts` 距今 ≤10 分钟、三项配额原值为 0；不满足 → `BUILD BLOCKED`，构建立即失败，不进入 checkout/build/回写。
3. **只读挂载**：`artifacts/quota` 以 bind mount 只读挂到 controller 与 agent 的 `/opt/orgflow/quota:ro`。构建前只消费证据，**不给 agent 挂 docker.sock**——任何"给 agent 挂 docker.sock 检查配额"的做法一律否决（M1 安全基线）。

## 4. 证据生命周期与自动刷新（m2.5.1 P0-1）

- **生命周期 10 分钟**：Quota gate 要求证据 `age ≤ 10min`。证据一旦超过 10 分钟，推任何 change 都会在 Quota gate 被 BLOCKED（自锁）。
- **timer 每 5 分钟刷新**：`deploy/systemd/orgflow-quota.service` + `orgflow-quota.timer`（`OnBootSec=2min`、`OnUnitActiveSec=5min`、`Persistent=true`），由 `make quota-install` 安装到 `/etc/systemd/system` 并 `enable --now`。真机（systemd PID1）必装；沙箱 PID1=supervisord 时 timer 不可用，需手动 `make quota-guard`。
- **部署后先确认再推代码**：部署顺序固定为 **`git pull` → `make check` → `up.sh --recreate/--pull` → `make quota-guard` → 再推代码**；随后 `make quota-status` 打印 timer 状态 + 证据 ts/age，`age>10min` 非 0 退出。推 change 前必须确认为 0，且自检报告 `commit` 必须等于当前部署头（未先 pull 就 reload 会让报告 commit 落后一版）。详见 [升级与回滚](升级与回滚.md)。
- **agent 绝不挂 docker.sock**：配额证据只由宿主侧采集，agent 只读消费。

## 5. 为什么不让 Agent 直接跑 docker

`orgflow-agent` 按设计不带 `docker.sock`。配额证据必须由宿主侧（有 docker 权限的 `up.sh` / `quota-guard.sh`）采集并落盘，agent 只读消费。这样构建容器无法自我放宽配额、也不扩大攻击面。

## 6. 反证记录（2026-11-27 实测）

| 场景 | 期望 | 实测 |
|---|---|---|
| 正常态 `of-builder`（配额全 0） | PASS，exit 0，四行原值 + 证据文件 | PASS，exit 0 ✓ |
| 容器不存在 | BLOCKED，exit 3，reason 写明缺失项 | exit 3 ✓ |
| `docker create --cpus 2` 临时容器 | BLOCKED，exit 2，`NanoCpus=2000000000` | exit 2 ✓ |
| 篡改证据 `ts` 为 1 小时前 | Quota gate `stale=61min` → BLOCKED | BLOCKED ✓ |
| 删证据文件 | Quota gate `evidence missing` → BLOCKED | BLOCKED ✓ |
| 启动前后宿主 nproc 变化（篡改 preflight） | BLOCKED `启动前后nproc变化(999→5)` | BLOCKED ✓ |
| `up.sh --only jenkins-agent` 后 | `latest-of-builder.json` 不变，Quota gate 仍 PASS | PASS ✓ |
| 恢复配额/证据后重跑 | PASS，推 change 可正常 SUCCESS | PASS ✓ |

BLOCKED 日志中不得出现 `full-quota PASS` 字样（已用 `grep -rn 'full-quota PASS' logs/` 核验）。
