# Contributor Covenant Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/)
v2.1.

By participating, you are expected to uphold this code: be respectful,
constructive and professional in all project spaces.

Instances of abusive, harassing, or otherwise unacceptable behavior may be
reported to the project team via the contact channel in [SECURITY.md](SECURITY.md).
All complaints will be reviewed and investigated.
